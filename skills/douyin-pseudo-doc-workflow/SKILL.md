# 抖音伪纪录片图文工作流

用户给一个故事，输出一整套可以直接照做的方案。图片有两种出法：

- **自动生图**：写一份分镜 JSON，运行 `scripts/generate_images.py` 调 OpenAI 生图接口一次出完，水印和文案由脚本画上去。用户要求自动生图，或者环境里设置了 `OPENAI_API_KEY` 时用这种
- **手动生图**：输出发给 GPT 的提示词，用户自己一张张生成。没有 API Key、用户想用 ChatGPT 网页版时用这种

拿不准用哪种时，检查 `OPENAI_API_KEY` 是否存在：有就自动，没有就手动，并在最后一句提一下可以配置 Key 改成自动。

## 输入
- 必需：故事。可以是一句梗概，也可以是完整情节
- 可选：张数（默认10张，范围8–15）、风格（恐怖/悬案/志怪/温情/哲思）、结局倾向（留悬念/揭晓/反转）
- 没给的按默认走，不要反复追问
- 用户说"要GPT总指令""想在GPT里自己跑"时，直接输出 [gpt-master-prompt.md](gpt-master-prompt.md) 的内容，加上用法说明，不用走下面的流程

## 自动生图流程

1. 按下面"输出"里的规则想好设定卡和分镜，但不用逐条打印 GPT 提示词
2. 在当前工作目录建一个文件夹（用故事的拼音或英文短名），写入 `storyboard.json`，格式见 [examples/diary.json](examples/diary.json)：
   - `style`：整体风格加固定元素，每张都会自动拼在提示词前面。不要写日期水印，脚本会加，也会自动叮嘱模型不画任何文字
   - `references`：定妆照，每个有 `id`、`name`、`prompt`
   - `shots`：每张有 `id`（从1开始的数字）、`caption`（配图文案）、`timestamp`（如 `2024/04/13 15:20`，不需要水印就写 `null`）、`refs`、`prompt`
   - `refs` 就是"上传什么"：写定妆照的 id（字符串）或前面某张的序号（数字）。同一场景的改图写那张母版图的序号，prompt 开头写"在这张图的基础上修改：……保持不变"。被参考的图必须排在前面
3. 先检查依赖：`python3 -c "import openai, PIL"`，缺了就 `pip install openai pillow`
4. 运行：`python3 <本skill目录>/scripts/generate_images.py <文件夹>/storyboard.json`。10张大约要几分钟，用后台运行，完成后再继续
5. 打开定妆照和几张成品看一下。明显走样、太精致或者出现乱码字的，改对应 prompt 后用 `--only 序号` 重做；脚本会提示哪些图参考了重做的图，问用户要不要一起重做
6. 把标题、正文和发布清单写进同一文件夹的 `post.md`，聊天里给出标题、成品文件夹路径和需要用户注意的地方

脚本参数：
- `--only 3 6`：只重做这几张（定妆照写 id）
- `--compose-only`：只重新加水印和文案，不花钱。改了 caption 或 timestamp 后用
- `--dry-run`：用灰色占位图走一遍流程，检查 JSON 写得对不对
- `--quality low|medium|high`：默认 medium
- `--fidelity high`：改图时更严格地保留输入图，走样多时加上
- `--model`：默认 `gpt-image-1`，也可以用环境变量 `OPENAI_IMAGE_MODEL` 换
- `--no-captions`、`--font 字体文件`：不加文案，或者指定中文字体

输出：`output/raw/` 是原图，`output/final/` 是加了日期水印的成品，`output/captioned/` 是又加了配图文案的版本（找不到中文字体时没有这个文件夹，让用户用醒图手动加）。

接口报错时脚本会停下并打印原因。内容审核拒绝的，改掉 prompt 里可能被误判的描述再重做；没有 Key 或额度不足的，告诉用户去 OpenAI 后台处理，同时退回手动生图，输出 GPT 提示词。

## 输出（手动生图时严格按此顺序；自动生图时第3、3.5节换成上面的流程）

### 1. 场景设定卡
后面所有提示词都依赖这张卡，必须先定好：
- **地点**：具体到材质和细节（如"深圳城中村，握手楼，窄巷，头顶缠着电线"）
- **标记物**：选一个贯穿全篇的物件，用来认出"我"或核心线索，写清颜色、材质、磨损（如"米白色旧帆布包，挂着掉漆的黄色小鸭挂件，左边翅膀掉漆"）。每张图尽量都出现
- **人物**：只写衣着，只拍背影、手或局部，不出正脸
- **设备与时间线**：老款安卓手机，右下角橙色日期水印；给每张定好日期和时刻，时间要前后对得上

### 2. 分镜表
每张一项：
- **序号**
- **配图文案**：一句话，第一人称，15–30字，平实口语，像真人日记
- **画面**：拍什么、光线、角度、曝光、出现哪些物件、水印时间

### 3. GPT 生图提示词
先写一句用法：新开 GPT 对话，先生成定妆照，再发设定，回"收到"后一次发一张，全程在同一个对话里。

**定妆照**（放进一个代码块，排在最前面）：让 GPT 单独生成一张标记物的参考图，用户存下来，后面反复上传。要求：标记物放在简单背景上，俯拍或正面，光线平淡均匀，能看清全貌；写出设定卡里的全部特征；手机随手拍质感、轻微噪点；不要水印、不要文字。标记物不止一个（比如还有一把椅子），就各出一张。

**设定段**（放进一个代码块），包含：
- 整体风格：老款安卓手机随手拍，明显噪点、轻微模糊、构图略歪、曝光不完美；业余拍摄、真实生活感；不要电影感、不要高清质感、不要完美光线、不要精修；竖版；右下角橙色数码日期水印；画面上不加其他文字
- 固定元素：设定卡里的地点、标记物、人物规则，原样写进去
- 结尾：先不用生成，回复"收到"

**逐张提示词**（每张一个代码块），格式：
```
第X张：[时间段]，[光线/曝光/构图问题]。[具体画面，写出标记物]。水印：YYYY/MM/DD HH:MM
```
特殊画面（翻拍屏幕、漆黑房间里亮着的手机等）写明"这张不需要日期水印"。

每张提示词的代码块上方标一行**上传什么**，按下面的规则选一种：
- **【上传定妆照】**：标记物出现、但场景没出现过。提示词开头加"参考我上传的这张图，[标记物]必须和它一模一样：[列出2–3个最关键的特征]。"
- **【上传第X张，改图】**：和前面某张是同一个场景（同一张书桌、同一条路）。先把那一张做满意，后面这些都基于它修改。提示词开头写"在这张图的基础上修改：[场景里要保持不变的东西]保持不变，只把画面改成……"。同一个场景出现3次以上时一定要用这种
- **【上传第X张】**：前面某张新出现的元素（红圈、挪了位置的椅子）这一张要延续。提示词里写明"[元素]和这张一样"
- **不用上传**：只有第一次出现的场景，而且没有标记物

### 3.5 生成顺序
用一张小表列出：先做定妆照，再做哪几张"母版图"（后面会被改图的那几张），最后做依赖它们的图。只列顺序和每张的依赖，不重复提示词。

### 4. 标题
3个备选，第一人称、短、带悬念，推荐其中一个并用一句话说明理由。

### 5. 正文
把故事写成一篇口语化的第一人称帖子，按图片顺序展开，比配图文案更详细，结尾不解释谜底。借用了别人作品的设定时，末尾加"（灵感来自《xxx》）"。

### 6. 发布清单与生图提示
- 选"图文"发布；自动生图的直接用 `captioned/` 里的图，手动生图的每张图角落用剪映或醒图加对应文案（不要让GPT写字，中文容易错）
- 标题用推荐的那个，正文用上面写的
- BGM：恐怖向用阴郁的，温情/哲思向用安静伤感的
- 勾选"内容由AI生成"声明
- 图太好看：回GPT"更像手机随手拍，加噪点，更模糊，构图再歪一点"
- 标记物走样：重新上传定妆照，回"只把[标记物]改成和参考图一样，其他都不要动"。只改走样的那一处，不要整张重来
- 必须一致的只有标记物、跨张延续的元素（如红圈）和人物的固定特征（如左手的表）；光线、角度、杂物位置有变化没关系，真实手机照片本来就这样

## 一致性规则
- 设定卡里的标记物特征控制在3–4个，挑最显眼的（颜色、材质、一个独特痕迹），写太多 GPT 顾不过来
- 同一场景反复出现时，优先设计成能"改图"的画面：机位相近，只换桌上的东西或光线
- 故事中途给标记物新增的变化（被圈出的字、新的划痕），从出现那一张起，后面每张提示词都要写上

## 分镜规则
- 第1张交代"我是谁、在做什么"，建立日常感
- 前3张必须平淡真实，第4张左右出现第一个微小异常
- 之后每张只升级一点，靠细节制造不对劲（位置变化、多出来的东西、时间对不上），不直接写鬼怪、血腥
- 最后一张留悬念或冷反转，不解释原因
- 温情/哲思类故事把"不对劲"换成"让人沉默或破防"，不要硬改成恐怖
- 句子短，少形容词

## 写实要点
- 必写：手机抓拍、噪点、模糊、构图歪、曝光问题
- 可加：无关杂物（垃圾袋、电线）、手指挡住一角、对焦失误、屏幕反光和摩尔纹（翻拍时）
- 禁用：电影感、8K、高清、大师摄影、完美构图、戏剧光影
- 每张提示词都写出标记物和地点的关键描述，不写"同上"
- 异常要克制，只比正常画面多一点点不对劲

## 内容边界
- 只做明确虚构的故事。不涉及真实案件、灾难、失踪事件和能认出来的真人，不伪造新闻、警情、官方通知
- 真实地名可以营造氛围，但不说那里真的发生过这件事
- 用户想改编在世作者的作品（如特德·姜、网络原创帖）：只借核心设定，人物和剧情重新写，并在正文注明灵感来源；不照搬情节和原文。古代志怪、民间说法可以放心改
- 发布清单里始终提醒勾选AI生成声明
